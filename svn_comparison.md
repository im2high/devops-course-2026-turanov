# Сравнение SVN и Git

1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?
    В Git ветка- это ссылка на коммит, в то время как в SVN ветка- это физическая копия репозитория внутри репозитория. При создании новой ветки в гит все происходит локально, в отличие от SVN, где происходит создание директории внутри репозитория.
2. Можно ли в SVN сделать коммит без интернета? Почему?
    Нельзя, так как все изменения при коммите отправляются сразу центральный сервер. В Git же коммит происходит локально,  а интернет необходим тольно для push/fetch.
3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
    В целом SVN проигрывает Git по части ветвеления и постоянной необходимости в подключении к сети, однако SVN может обеспечивать более тонкую настройку прав доступа, и он более подходящий для небольших проектов, где не нужно большое количество веток.ы
